# lunchb0ne.me

Source code for my personal site, [lunchb0ne.me](https://lunchb0ne.me).

Built with [Next.js](https://nextjs.org/), TypeScript, Sass, and a bit of
Three.js for the 3D bits.

## Development

```bash
yarn install
yarn dev      # start the dev server at http://localhost:3000
yarn build    # production build
yarn lint     # run eslint
```

## Structure

- `pages/` — routes (home, blog, work case studies, 404)
- `components/` — UI components
- `content/work/` — project write-ups in MDX
- `styles/` — Sass modules
